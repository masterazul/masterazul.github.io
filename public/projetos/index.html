Cinco ferramentas em Rust.

Cada uma nasceu de um problema que apareceu no trabalho e não tinha ferramenta do jeito que eu precisava. Todas em Rust, com teste e CI rodando clippy no modo estrito. O maior binário tem 724 KB e nenhuma delas exige runtime instalado. Actions do CI pinadas por digest, zero linha de unsafe e varredura semanal de vulnerabilidade nas dependências. 01

spectra

masterazul/Spectra

Consultar CNPJ, CEP, DNS e certificado de um domínio significava abrir meia dúzia de sites. Aqui são 18 fontes públicas numa CLI só, todas devolvendo o mesmo formato de JSON. E tem o verify: antes de sair coletando, ele diz quais fontes estão de pé.

  • Rust
  • OSINT
  • CLI
  • Threat Intel
$ spectra verify
[  up] cep-viacep           cep              534ms
[  up] cnpj-brasilapi       cnpj             243ms
[  up] domain-crtsh         domain         10853ms
[down] ip-rdap              ip             12019ms  transport error

Saída real. A fonte fora do ar é do provedor, não da ferramenta — e é exatamente para isso que o verify existe: descobrir antes de coletar, não no meio.

02

keyrot

masterazul/keyrot

A senha não cifra os segredos. Ela deriva, com Argon2id, a chave que embrulha outra chave — e é essa que cifra. Assim trocar a senha não obriga a re-cifrar nada. Todo put cria uma versão nova em vez de sobrescrever, e cada operação vira uma linha num log encadeado por SHA-256. Mexeu no histórico, o verify acusa.

  • Rust
  • Criptografia
  • AEAD
  • Auditoria
$ keyrot put db/senha 's3cr3t'
stored version 1
$ keyrot rotate db/senha --generate
stored version 2
$ keyrot get db/senha --version 1
s3cr3t
$ keyrot verify
audit chain ok (5 entries)

kostwatch

masterazul/kostwatch

O time pede 2 vCPUs e usa 0,1. Multiplica por réplica e por mês: vira dinheiro parado. O kostwatch confronta o que foi pedido com o que roda de verdade — lendo um snapshot ou o Prometheus direto — e devolve a conta, do maior desperdício para o menor.

  • Rust
  • Kubernetes
  • Prometheus
  • FinOps
$ kostwatch analyze --snapshot snapshot.json
monthly cost: 448.95 USD   potential savings: 196.56 USD (44%)
payments  api          197.10  164.40  1.00->0.15  cpu-overprovisioned
legacy    cron-runner   32.85   32.15  0.50->0.01  idle
search    indexer      219.00    0.00  2.00->2.00

O indexer aparece com economia zero: o uso acompanha o pedido. A ferramenta não inventa corte onde não há.

habitsync

masterazul/habitsync

Feito para app que precisa funcionar no avião. O cliente grava tudo offline; quando a rede volta, manda num POST só e recebe de volta apenas o que mudou desde o último cursor. Conflito resolve por last-write-wins. Não tem banco: o estado é um arquivo JSON gravado de forma atômica.

  • Rust
  • HTTP
  • Delta sync
  • Offline-first
$ curl -s localhost:8787/analytics
[{"id":"h1","name":"Ler 20 paginas",
  "current_streak":3,"longest_streak":3,
  "total":3,"rate_30d":0.1}]
